# GreenDye for Training and Consultancy V20

V20 resolves the source-level P0 and P1 findings from the V19 review: integration contract alignment, replica-set CI, safe MongoDB initialization, database tools, controlled privilege drop, modern credential APIs, removal of Green-hosted LMS event types, centralized Axios transport, and expanded readiness checks.

Final production certification still requires connected staging execution of Docker image builds, Docker Compose startup, process-user verification, ClamAV clean/EICAR/fail-closed checks, backup and restore drills, SMTP delivery, dependency/image/secret scans, load testing, and signed payment-webhook reconciliation.
