# Green Global Consulting architecture

## Audiences
Individuals, organizations, companies, and factories worldwide.

## Core domain
- Consultation services
- Consultation requests
- Consultants and professional accreditation
- Trainers and trainer verification
- Certificates and QR verification
- Consulting projects, proposals, contracts, deliverables, invoices, and payments (next implementation phase)

## Current API
- `GET /api/consulting/services`
- `GET /api/consulting/services/:slug`
- `POST /api/consulting/requests`
- `GET /api/consulting/requests/mine`
- Administrative service and request endpoints under `/api/consulting/admin`
- Public verification under `/api/verify`
