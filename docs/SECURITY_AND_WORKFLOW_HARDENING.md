# Security and workflow hardening

Implemented: project membership and granular permissions, object-level project access, immutable audit events, controlled state-transition utilities, change requests, risks, meetings, NDAs, payment ledger with idempotency, server-side invoice calculator, private versioned document storage with SHA-256, automatic progress/health recalculation, multi-role users, and accreditation expiry job.

Operational requirements: run malware scanning before production, place private uploads on encrypted object storage, configure a real scheduler for `npm run expire-accreditations`, review tax rules with qualified advisers, and use a legally compliant signature provider before representing approvals as qualified electronic signatures.
