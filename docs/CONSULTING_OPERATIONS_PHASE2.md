# Consulting operations phase 2

Implemented domain models and APIs for proposals, consulting projects, milestones, tasks, deliverables, contracts, and invoices. Accepting a proposal creates a project. Role guards protect administrative, project management, technical review, and finance operations.

This release does not process live payments or electronic signatures. Invoice status and contract signatures are records managed by authorized users. File uploads for deliverables should be connected to the existing secure media subsystem in a later hardening pass.
